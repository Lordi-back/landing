⚖️ Юридический AI Ассистент

Полноценное десктопное приложение для автоматического анализа документов

🎯 Что делает

  • Анализ юридических рисков (двусмысленности, противоречия)
  • Проверка орфографии и стиля (канцеляризмы, ошибки)
  • Контроль соответствия законам (ссылки, обязательные пункты)

🛠️ Технологический стек

WPF + XAML — Интерфейс пользователя C# .NET 8.0 — Логика приложения PdfPig — Парсер PDF OpenXml — Парсер DOCX Newtonsoft.Json — База законов (sources.json) Inno Setup — Инсталлятор (~55 MB)

✅ Ключевые фичи

  • Поддержка PDF, DOCX, TXT
  • 3 параллельных агента анализа
  • Цветовая подсветка проблем в тексте
  • Hyperlink'и на законы в браузере
  • Инсталлятор с автоустановкой .NET
  • Работает на Windows 7–11
  • Полностью локально — документы не покидают компьютер

📊 Avito Industrial Parser

Парсер + верификатор данных промышленного магазина Avito

🎯 Задача

  • Парсинг 8,461 позиции из 1,500 объявлений Avito
  • Извлечение 20 полей данных в Excel
  • Верификация и дополнение пустых полей (1,610 проблемных строк)

🛠️ Ключевые технологии

Python 3 — Основной язык Selenium WebDriver — Автоматизация Chrome Pandas — Работа с Excel Regex (re) — Извлечение маркировок, цен webdriver-manager — Автоустановка драйвера JSON — Сохранение прогресса

🔧 Решённые проблемы

  • Латиница в русском тексте (HOBЫЙ → НОВЫЙ) — нормализация символов
  • Мультипозиции (Mitsubishi, Wika) — отдельные парсеры
  • Защита от блокировки — задержки 3–8 сек, паузы каждые 30 товаров
  • Сохранение прогресса — можно прервать и продолжить

📈 Результат

  • 95% брендов определено автоматически
  • 20 версий скрипта (от v1.0 до v20.1)
  • 40+ брендов в словаре
