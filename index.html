Юридический AI Ассистент

Полноценное десктопное приложение для автоматического анализа юридических документов

🎯 Что делает

  • Анализ юридических рисков (двусмысленности, противоречия)
  • Проверка орфографии и стиля (канцеляризмы, ошибки)
  • Контроль соответствия законам (ссылки, обязательные пункты)
  • Подсветка проблем прямо в тексте документа

🛠️ Технологический стек

WPF + XAML — Интерфейс пользователя C# .NET 8.0 — Логика приложения PdfPig — Парсер PDF OpenXml — Парсер DOCX Newtonsoft.Json — База законов (sources.json) Inno Setup — Инсталлятор

🏗️ Архитектура приложения

┌─────────────────────────────────────────┐ │ WPF Application │ ├─────────────────────────────────────────┤ │ UI Layer │ │ • MainWindow.xaml — интерфейс │ │ • RichTextBox — текст с подсветкой │ │ • ItemsControl — список проблем │ ├─────────────────────────────────────────┤ │ Business Logic Layer │ │ • UnifiedAnalyzer — координация │ │ • LawChecker — проверка законов │ │ • GrammarChecker — орфография │ │ • RiskChecker — риски │ ├─────────────────────────────────────────┤ │ Data Layer │ │ • sources.json — база законов │ │ • DocumentParser — PDF/DOCX/TXT │ └─────────────────────────────────────────┘

✅ Ключевые возможности

  • Поддержка PDF, DOCX, TXT
  • 3 параллельных агента анализа
  • Цветовая подсветка: красный / жёлтый / зелёный
  • Hyperlink'и на законы в браузере
  • Инсталлятор ~55 MB с автоустановкой .NET

🔒 Безопасность

  • Работает полностью локально
  • Документы не покидают компьютер
  • Не требует подключения к интернету
  • Поддержка Windows 7–11
💡 Идеально для юридических фирм, работающих с конфиденциальными документами

📋 База знаний (sources.json)

{ "laws": { "civil_code": { "name": "Гражданский кодекс РФ", "url": "https://www.consultant.ru/..." } }, "required_clauses": [...], // Обязательные пункты договора "risk_patterns": [...], // Опасные формулировки "bureaucracy_phrases": [...], // Канцеляризмы "forbidden_terms": [...] // Запрещённые слова }

Family Shopping List

Семейный планировщик покупок с синхронизацией в реальном времени

🎯 Возможности

  • Ведение общего списка продуктов для всей семьи
  • Планирование покупок без лишних трат
  • Realtime-синхронизация между всеми устройствами
  • Telegram-бот для быстрого добавления продуктов
  • Установка как PWA на главный экран телефона

🛠️ Технологический стек

Next.js 14 — Фронтенд (React + TypeScript) Tailwind CSS — Стилизация Supabase — База данных (PostgreSQL + Realtime) Python-Telegram-Bot — Telegram-бот Vercel + Railway — Бесплатный деплой 24/7

📱 Веб-приложение (PWA)

  • Работает как обычный сайт
  • Можно установить на телефон как нативное приложение
  • Адаптивный дизайн для всех устройств
🔗 Ссылка: shoppinglist-navy.vercel.app

🤖 Telegram-бот

  • /start — начало работы
  • /code КОД — присоединиться к семье
  • /list — что в холодильнике
  • /add продукт — добавить продукт
  • /shopping — список покупок
  • /recipes — рецепты из того, что есть
🤖 Бот работает 24/7 через Railway и не требует включённого телефона

👨‍👩‍👧‍👦 Как это работает для семьи

  • Папа добавил молоко — у мамы и детей сразу видно
  • В магазине: открываешь /shopping — видишь, что нужно купить
  • Дома: проверяешь холодильник через /list перед походом в магазин
  • Рецепты: /recipes показывает, что можно приготовить из имеющихся продуктов

🎯 Какие проблемы решает

«А купили ли мы молоко?» «Зачем я купил третий пакет?» «Что сегодня приготовить?» «Вечно забываю хлеб» «Разные списки у всех»
💡 Итог: Full-stack проект с реальной пользой для семьи. Next.js + Supabase + Telegram Bot. Realtime-синхронизация, семейная система, PWA, готов к использованию.

Industrial Data Parser

Извлечение и верификация данных из промышленного каталога товаров

🎯 Задача

  • Парсинг структурированных данных из онлайн-каталога
  • Извлечение 20 полей данных в Excel
  • Верификация и дополнение пустых полей в проблемных строках

🛠️ Ключевые технологии

Python 3 — Основной язык Selenium WebDriver — Автоматизация браузера Pandas — Работа с Excel Regex (re) — Извлечение маркировок webdriver-manager — Автоустановка драйвера JSON — Сохранение прогресса

📊 Извлекаемые поля (20 столбцов)

  • Состояние, Производитель, Заголовок
  • Описание, Маркировка, Количество
  • Цена, Ссылка, Изображение
  • Страна, Город, Цена полная, Цена чистая
  • Доставка, Продавец, Ссылка продавца
  • Название, Время создания, Время обновления, ID

🔧 Решённые проблемы

  • Латиница в русском тексте: нормализация символов (HOBЫЙ → НОВЫЙ)
  • Мультипозиции: отдельные парсеры для каждого формата
  • Защита от блокировки: задержки 3–8 сек, паузы каждые 30 товаров
  • Сохранение прогресса: JSON-файл, можно прервать и продолжить

🔧 Ключевые методы верификации

  • Автосбор словаря брендов — извлечение всех уникальных брендов из файла
  • Парсинг страниц — извлечение описания, маркировки, бренда, состояния
  • Поиск бренда — сначала в блоке «Производитель», затем в тексте объявления
  • Регулярные выражения — для извлечения артикулов различных форматов
  • Защита от блокировки — задержки 3–7 сек, паузы каждые 30 строк

📈 Результат

  • 95% брендов определено автоматически
  • 20+ итераций скрипта
  • 40+ брендов в словаре
💡 Вход: исходный Excel-файл → Выход: верифицированный файл + лог изменений в JSON

🛡️ Меры защиты

  • Задержки между запросами: 3–8 секунд
  • Паузы каждые 30 позиций
  • Сохранение прогресса каждые 10 строк
  • Возможность прервать и продолжить с того же места
